# Project instructions

## Planning

Keep plans, spike plans, roadmaps, and task breakdowns outside this repository. Do not create or maintain planning documents in the repo; discuss proposed work in the conversation or the project's external planning tools.

## Git workflow

Make changes on a separate branch and submit them through a pull request. Never push directly to the repository's default branch.

Create each new branch from the latest remote default branch, never from another feature branch. Keep pull requests independent and target the default branch; never stack branches or pull requests. If work depends on an unmerged pull request, wait for it to merge before creating the dependent branch from the updated default branch.
